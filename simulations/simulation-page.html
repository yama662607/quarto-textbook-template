## シミュレーションの使い所 {#sec-simulation-use-case}

- 理論ページを読んだ後に手を動かす
- パラメータを変えて挙動を比較する
- 発表中に図だけを素早く見せる
- 本文が長くなりすぎる場合に動的要素を分離する

## 最小可動例

```{ojs}
//| echo: false
viewof sim_amplitude = Inputs.range([0.2, 2.0], {step: 0.1, label: tex`\text{振幅 } A`, value: 1.0})
viewof sim_frequency = Inputs.range([0.5, 4.0], {step: 0.1, label: tex`\text{周波数 } f`, value: 1.5})
```

```{pyodide}
#| autorun: true
#| input: ["sim_amplitude", "sim_frequency"]
import os
import warnings
import matplotlib
from matplotlib import font_manager

warnings.simplefilter("ignore")

try:
    from pyodide.http import pyfetch

    font_path = "/tmp/NotoSansJP.ttf"

    def valid_ttf(path):
        if not os.path.exists(path) or os.path.getsize(path) < 1_000_000:
            return False
        with open(path, "rb") as f:
            return f.read(4) in (b"\x00\x01\x00\x00", b"OTTO", b"ttcf")

    if not valid_ttf(font_path):
        resp = await pyfetch("/assets/fonts/NotoSansJP-Regular.ttf")
        font_bytes = await resp.bytes()
        with open(font_path, "wb") as f:
            f.write(font_bytes)
    if valid_ttf(font_path):
        font_manager.fontManager.addfont(font_path)
        matplotlib.rcParams["font.family"] = "Noto Sans JP"
except Exception:
    pass
matplotlib.rcParams["axes.unicode_minus"] = False

import numpy as np
import matplotlib.pyplot as plt
from matplotlib.animation import FuncAnimation
from IPython.display import HTML

t = np.linspace(0, 2.0, 400)
n_frames = 48

fig, ax = plt.subplots(figsize=(7, 3.5))
(line,) = ax.plot([], [], lw=2)
title = ax.set_title("")
ax.set_xlim(0, 2.0)
ax.set_ylim(-2.2, 2.2)
ax.set_xlabel("時間 $t$")
ax.set_ylabel("変位 $x(t)$")
ax.grid(True, linestyle="--", alpha=0.45)

def update(i):
    phase = 2 * np.pi * i / n_frames
    y = sim_amplitude * np.sin(2 * np.pi * sim_frequency * t + phase)
    line.set_data(t, y)
    title.set_text(f"単振動: A={sim_amplitude:.1f}, f={sim_frequency:.1f}")
    return line, title

ani = FuncAnimation(fig, update, frames=n_frames, interval=60, blit=False)
plt.close(fig)
HTML(ani.to_jshtml())
```

## 配置の考え方

`simulations/simulation-page.qmd` のように独立ページとして作り、`_quarto.yml` では「演習・シミュレーション・補助資料」などの part に入れます。ホームには「動く教材」として表でリンクします。

より複雑な Quarto Live / Plotly の書き方は、[教材本編サンプルのシミュレーション教材](../textbook/textbook.qmd#sec-simulation-showcase) をコピー元にしてください。
