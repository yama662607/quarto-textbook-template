問題

ヒント単振動の読み取り

変位が

x(t) = A \sin(2\pi f t)

で表されるとします。A = 1.5, f = 2.0 のとき、周期 T と最大速度 v_{\max} を求めてください。

ヒント

ノート見るべき式

周期は T = 1/f です。速度は x(t) を時間微分して求めます。

可視化の確認

シミュレーションページでは、振幅と周波数を変えたときに波形がどう変わるかを確認できます。演習ページに動く図を直接置きたい場合は、シミュレーションページ の最小可動例をコピーしてください。

import numpy as np
import matplotlib.pyplot as plt

A = 1.5
f = 2.0
t = np.linspace(0, 1.0, 400)
x = A * np.sin(2 * np.pi * f * t)

plt.plot(t, x)
plt.xlabel("time")
plt.ylabel("x(t)")
plt.grid(True)
plt.show()

解答方針

重要解答

周期は

T = \frac{1}{f} = \frac{1}{2.0} = 0.5

です。速度は

v(t) = \frac{dx}{dt} = 2\pi f A \cos(2\pi f t)

なので、最大速度は

v_{\max} = 2\pi f A = 6\pi

です。

よくある間違い

注意単位と記号をそろえる

角周波数 \omega と周波数 f を混同しないでください。\omega = 2\pi f なので、x(t)=A\sin(\omega t) と書く場合と x(t)=A\sin(2\pi f t) と書く場合で、係数の意味が変わります。

発展問題

  • 位相 \phi を入れた x(t)=A\sin(2\pi f t + \phi) では、v_{\max} は変わるでしょうか。
  • 減衰項 e^{-\gamma t} を掛けると、最大振幅は時間とともにどう変化するでしょうか。

## 問題

::: {.callout-tip}
## 単振動の読み取り

変位が

$$
x(t) = A \sin(2\pi f t)
$$

で表されるとします。$A = 1.5$, $f = 2.0$ のとき、周期 $T$ と最大速度 $v_{\max}$ を求めてください。

:::

## ヒント

::: {.callout-note collapse="true"}
## 見るべき式

周期は $T = 1/f$ です。速度は $x(t)$ を時間微分して求めます。

:::

## 可視化の確認

シミュレーションページでは、振幅と周波数を変えたときに波形がどう変わるかを確認できます。演習ページに動く図を直接置きたい場合は、[シミュレーションページ](../simulations/simulation-page.qmd) の最小可動例をコピーしてください。

```python
import numpy as np
import matplotlib.pyplot as plt

A = 1.5
f = 2.0
t = np.linspace(0, 1.0, 400)
x = A * np.sin(2 * np.pi * f * t)

plt.plot(t, x)
plt.xlabel("time")
plt.ylabel("x(t)")
plt.grid(True)
plt.show()
```

## 解答方針

::: {.callout-important collapse="true"}
## 解答

周期は

$$
T = \frac{1}{f} = \frac{1}{2.0} = 0.5
$$

です。速度は

$$
v(t) = \frac{dx}{dt} = 2\pi f A \cos(2\pi f t)
$$

なので、最大速度は

$$
v_{\max} = 2\pi f A = 6\pi
$$

です。

:::

## よくある間違い

::: {.callout-caution}
## 単位と記号をそろえる

角周波数 $\omega$ と周波数 $f$ を混同しないでください。$\omega = 2\pi f$ なので、$x(t)=A\sin(\omega t)$ と書く場合と $x(t)=A\sin(2\pi f t)$ と書く場合で、係数の意味が変わります。

:::

## 発展問題

- 位相 $\phi$ を入れた $x(t)=A\sin(2\pi f t + \phi)$ では、$v_{\max}$ は変わるでしょうか。
- 減衰項 $e^{-\gamma t}$ を掛けると、最大振幅は時間とともにどう変化するでしょうか。
